## 🚀 Platform Detection & Optimization

```
WordPress (43.5% of web)
├─ Characteristics: Heavy, plugin-laden, slower page loads
├─ Detected by: wp-content, wp-includes, WordPress headers
├─ Optimizations:
│  └─ Timeout: 25s (max)
│  └─ Network wait: 7s (generous)
│  └─ Concurrency: 4-5 (don't overload shared hosting)
└─ Preset suggestion: Thorough or Enterprise

SPA / Headless (Growing rapidly)
├─ Characteristics: Fast, JS-heavy, hydration needed
├─ Detected by: React, Vue, Angular headers, SPA patterns
├─ Optimizations:
│  └─ Timeout: 15s (faster JS rendering)
│  └─ Network wait: 3s (APIs respond quickly)
│  └─ Concurrency: 6-8 (can handle high parallelism)
└─ Preset suggestion: Quick Scan or Comprehensive

E-commerce (Shopify 6.2%, custom)
├─ Characteristics: Product catalogs, faceted search, variants
├─ Detected by: product.json, /products/, cart.js
├─ Optimizations:
│  └─ Timeout: 20s (balanced)
│  └─ Network wait: 6s (many API calls)
│  └─ Concurrency: 6-7 (product pages are similar)
│  └─ Dedup strategy: Aggressive (same product, diff variants)
└─ Preset suggestion: Thorough or Enterprise

Custom Build (11% of web)
├─ Characteristics: Varies widely by framework
├─ Detected by: No known framework signatures
├─ Optimizations:
│  └─ Timeout: 20s (standard)
│  └─ Network wait: 5s (reasonable default)
│  └─ Concurrency: 5 (cautious)
└─ Preset suggestion: Comprehensive (safe default)
```

## 📱 Mobile & Performance Factors

```
Page Weight Trends (2026)
└─ Average: 2.3 MB per page
└─ Growth: +15% from 2022
└─ Image content: 70% of weight (mostly lazy-loaded)

Lazy Loading Impact
├─ Homepage: Might load 200 KB visible
├─ Below fold: Another 1.8 MB lazy-loaded
└─ Crawler implication: Need to wait for lazy load

Network Performance
├─ LCP (Largest Contentful Paint): 2.5s avg
├─ Mobile slower than desktop by 15-30%
└─ Your timeouts account for this: 15-25s is safe

Mobile Traffic Dominance (59%)
├─ More pages per session on desktop
├─ But more total users on mobile
└─ Crawler: Focus on desktop for consistency
```
